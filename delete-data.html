Richiesta di cancellazione dei dati — MotoLink

Questa pagina spiega come eliminare l'identità tecnica anonima dell'Assistente e i dati locali di MotoLink. Ultimo aggiornamento: 28 ottobre 2026.

Con l'app installata

  1. Apri Supporto → Log.
  2. Premi Pulisci e seleziona ELIMINA SESSIONE (non Pulisci Log).
  3. Conferma la richiesta. Il server verifica la sessione anonima, la elimina e l'app cancella i token solo dopo conferma del server.

La cancellazione della sessione non rimuove profili moto, impostazioni o Log sul telefono. Un successivo uso dell'Assistente può creare una nuova sessione. Il comando è disponibile nelle versioni che includono questa funzione.

Se non hai più l'app o il comando non è disponibile

Scrivi all'indirizzo ufficiale per chiedere assistenza con l'eliminazione dei dati ancora identificabili. Le sessioni anonime non sono necessariamente riconducibili a un nome o indirizzo email: dopo disinstallazione o perdita della sessione potrebbe non essere tecnicamente possibile identificarne il record. Non inviare password, token o codici QR completi.

Richiedi cancellazione via email

Contatto: motolinkofficial.app@gmail.com

Per cancellare i dati locali

Il Log viene rimosso con Supporto → Log → Pulisci → Pulisci Log. Profili moto, foto, preferenze e impostazioni si eliminano da Impostazioni Android → App → MotoLink → Spazio di archiviazione → Cancella dati, oppure disinstallando MotoLink.

Queste operazioni non cancellano automaticamente email già inviate o dati custoditi da servizi terzi indipendenti.

MotoLink — Data deletion request

This page explains how to delete the Assistant's anonymous technical identity and MotoLink's local data. Last updated: 28 October 2026.

With MotoLink still installed

  1. Open Support → Log.
  2. Choose Clear, then DELETE SESSION (not Clear Log).
  3. Confirm. The server verifies and deletes the anonymous session; the app clears local tokens only on server confirmation.

Deleting the session does not remove motorcycle profiles, settings or the phone's technical log. Using the Assistant again can create a new session. This action is available in versions that include it.

Without the app or deletion action

Email MotoLink to request help deleting any data that can still be identified. Anonymous sessions may not be linked to a person's name or email address: after uninstalling or losing the session, identifying its Supabase record may be technically impossible. Never email passwords, tokens or complete QR codes.

Email a deletion request

Contact: motolinkofficial.app@gmail.com

Deleting local app data

Clear logs via Support → Log → Clear → Clear Log. Delete motorcycle profiles, photos, settings and other local data through Android Settings → Apps → MotoLink → Storage → Clear data, or uninstall MotoLink.

These actions do not automatically delete previously sent emails or records held independently by third-party providers.
